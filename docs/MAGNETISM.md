## 모델과 입력

모든 점은 같은 극성으로 자기장에 반응하며, 기본 중앙 + 자기장에 끌려 중앙으로 모인다. 점 색상은 도형에 사용하는 공유 팔레트에서 무작위로 선택한다. 캔버스의 튕기기 버튼은 위쪽 편향 없이 화면 중앙에서 방사형으로 점을 퍼뜨리며 `blur_on` 심볼을 사용한다. 중앙 + 자기장은 ‘중력 ON/OFF’ 버튼으로 켜고 끄며, 끄면 커서·터치 위치의 자기장만 남는다. 극성 전환은 커서·터치 자기장에만 적용하고 중앙은 항상 +를 유지한다. 중앙 자기장 위치에는 표시점을 그리지 않는다. 커서 극성 버튼은 ‘+극’/‘−극’으로 표시한다. 점은 기본 300개, 120~600개 범위에서 조절할 수 있고 반지름은 1.5~8px다. 개수를 늘릴 때 기존 점의 위치·속도·색상은 유지하고 새 점만 덧붙인다. 줄일 때는 뒤에 추가된 점부터 제거한다. P 키도 커서 극성을 전환하고 방향키는 키보드 자기장 위치를 이동한다. 터치·클릭 입력은 기존 InputManager의 포인터 좌표와 캡처를 사용하고, 누르지 않은 마우스·펜 이동은 장면의 hover 이벤트로 처리한다.

단순화된 교육용 근사 모델이며 실제 전자기장이나 자기 쌍극자 간 상호작용을 계산하지 않는다. 입자는 화면상 겹침 방지와 반발을 위한 간단한 원형 충돌 처리를 한다. 거리 제곱에 완화 항을 더해 0거리 특이점을 피하고, 방향벡터를 곱해 먼 거리에서는 대략 역거리 크기의 힘이 되도록 구성했다. 합산 가속도는 초당 제곱 픽셀 기준 800, 속도는 초당 180으로 제한하며 시간 기반 감쇠를 적용한다. 힘 세기 0은 추가 가속도를 없애며 기존 속도는 감쇠한다.

입자는 기본 300개, 설정에 따라 최대 600개다. 터치 자기장은 최대 4개이며 중앙 자기장이 켜진 일반 모드에서는 이를 합쳐 최대 5개만 계산한다. 충돌은 공간 그리드로 같은 셀과 인접 셀의 후보만 검사하며, 겹침이 심한 경우 최대 24회 보정한다. 입자가 골고루 분포할 때는 전체 쌍 전수 검사보다 적은 연산으로 처리하지만, 한 셀에 입자가 몰리는 최악의 경우 후보 검사는 여전히 O(N²)일 수 있다. 자기장 가속도 계산은 장면마다 재사용하는 결과 객체를 사용한다. DOM 입자·독립 RAF·Matter 엔진·타이머·추가 라이브러리는 없다.

초기화는 점 300개·기본 힘·커서 +·중앙 + 자기장 켜짐으로 복원한다. 화면 크기가 바뀌어도 선택한 점 개수를 유지하며, 크기 변경 시 입자를 새 화면 크기에 맞춰 재배치한다. 일시 정지/탭 숨김에는 공통 관리자에서 입력을 비우며 hover·키보드 자기장을 해제한다. 종료 시 장면 이벤트와 입자·캔버스 참조를 해제한다.

## 실제 검증

Node v22.23.4에서 실행:

```sh
node tests/magnetism.mjs
node tests/foundation.mjs
node tests/gravity.mjs /private/tmp/motio-matter-0.20.0.cjs
node tests/elastic.mjs /private/tmp/motio-matter-0.20.0.cjs
```

- 폭 280/720 × 힘 0/3의 네 조합에서 총 4,800스텝: 유한 좌표, 경계, 속도 상한 검사 통과.
- 커서 극성에 따른 인력/척력 방향, 0거리, 힘 0, 극성 전환 검사 통과.
- 8개 포인터 입력에도 추가 자기장 4개 제한, 기본 입자 120개 유지 확인.
- 커서 진입/이탈, 포인터 좌표, 방향키 자기장, P 전환, 정지·재개, 크기 변경 검사 통과.
- 종료 후 이벤트 비활성화, 렌더링 해제, 100회 생성/종료 검사 통과.
- 점 개수 300/600개·크기 슬라이더, 공유 팔레트 색상, 중앙 자기장 토글, 커서 극성 표기 및 중앙 표시점 제거 검사 통과.
- 기존 Foundation·Gravity·Elastic 회귀 검증 및 수정 JavaScript 구문 검사 통과.

해당 4,800스텝 및 관련 검사는 이 환경에서 약 334ms에 완료됐다. 이는 Node와 Canvas/DOM 대역을 사용한 전체 테스트 시간이며 브라우저 프레임 시간·60fps·실기기 메모리 안정성을 입증하지 않는다.

## 수동 확인 절차와 남은 사항

로컬 HTTP 서버에서 `index.html#magnetism`을 연다.

1. 모든 점이 같은 극성으로 반응하고 점 색상이 공유 도형 팔레트에서 무작위로 정해지는지 확인한다.
2. 점 개수·크기 슬라이더, 중앙 + 자기장 켜기/끄기, 커서 극성 전환을 확인한다.
3. 중앙 자기장을 켜고 끌 때 중앙 표시점은 나타나지 않고, 커서 극성 버튼이 ‘+극’/‘−극’으로 바뀌는지 확인한다.
4. 터치·다중 터치·포인터 취소·캔버스 밖 이동, 초기화, Tab·방향키·P 및 정지/재개를 확인한다.
5. 직접 hash 진입·새로고침·뒤로/앞으로, 다른 실험으로 전환, 탭 숨김/복귀를 확인한다.
6. 1440/1024/390/320 화면과 모바일 회전에서 레이아웃·입자 가독성을 비교하고 프레임 시간·메모리를 측정한다.

브라우저 화면 비교와 모바일 실기기 검증은 실행하지 못했다. 실제 프레임 시간·메모리 프로파일링도 남아 있다. 06 이후 기능은 구현하지 않았다.
