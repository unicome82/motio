## 동작과 한계

`#cloth`에서 천의 점 근처를 눌러 드래그한다. 포인터 캡처와 좌표는 기존 입력 관리자를 사용한다. 핀 추가·해제 버튼을 누른 뒤 점을 누르면 해당 점을 고정하거나 해제한다. 두 끝 고정점은 항상 유지된다. 추가 고정점도 검은 점으로 표시한다. 고정한 점을 움직이려면 먼저 고정을 해제한다.

캔버스 크기에 맞춰 천을 배치할 때 상단 약 40%는 비워 두고, 천은 세로 영역의 약 50%를 차지한다.

캔버스에 키보드 포커스를 두면 가운데 점이 선택되고 파랑 윤곽선이 표시된다. N으로 다음 점 선택, 방향키로 선택한 점 당기기, P로 고정 전환이 가능하다. 선택한 점이 고정점이면 방향키로 이동하지 않는다.

폭 480 미만은 13×11=143개 점과 12회 제약 반복, 그 외는 17×13=221개 점과 16회 반복을 사용한다. 노드의 관성·감쇠·중력을 Verlet 방식으로 계산하고 거리 제약을 PBD로 보정한다. 포인터 목표점은 스텝당 최대 8만큼 추적하며 관성 이동량과 캔버스 경계를 제한한다. 천 자체 충돌·찢기·3D 접힘은 구현하지 않았다.

정지·포커스 이탈·포인터 취소에는 잡기를 해제한다. 재개 후 천의 물리 계산을 이어간다. 초기화는 천·추가 핀·핀 모드를 기본 상태로 복원한다. 화면 크기 변경 시 천과 핀을 재생성하며, DPR만 바뀌면 상태를 유지한다. 핀 모드의 켜짐/꺼짐 선택은 크기 변경 후에도 유지한다. 추가 RAF·타이머·라이브러리·Matter 엔진은 없다.

## 실제 검증

Node v22.23.4에서 다음 검사 통과:

```sh
node tests/cloth.mjs
node tests/foundation.mjs
node tests/gravity.mjs /private/tmp/motio-matter-0.20.0.cjs
node tests/elastic.mjs /private/tmp/motio-matter-0.20.0.cjs
node tests/magnetism.mjs
node tests/wave.mjs
```

- 폭 280/720에서 총 3,600스텝. 초기 600스텝씩 화면 밖 양방향 목표로 당긴 후 놓는 스트레스 검사에서 유한 좌표와 캔버스 경계 유지.
- 양 끝 고정점 좌표 유지, 이완 후 모든 제약의 상대 길이 오차 15% 미만 확인.
- 추가 핀 좌표 유지와 해제, 양 끝 고정 해제 방지, 가까운 점 선택 확인.
- 장면에서 핀 토글, 드래그·취소, 정지·재개, 143→221개 점 resize, 격자·점 렌더링 확인.
- 모델 자원 해제와 100회 장면 생성·종료 후 버튼 이벤트 비활성화 확인.
- 기존 다섯 자동 검증과 수정 JavaScript 구문 검사 통과.

숫자 계산은 실제 모델을 사용하지만 Canvas·DOM·일부 포인터 동작은 대역이다. 실제 브라우저 시각 품질·터치·장시간 메모리·프레임 시간을 검증한 것은 아니다.

## 수동 확인과 남은 사항

로컬 HTTP 서버에서 `index.html#cloth`에 접속한다.

1. 점을 당겼다 놓기, 양 끝 고정, 천의 처짐과 이완을 확인한다.
2. 핀 모드에서 추가·해제, 동시 드래그 최대 4개, 포인터 취소·캔버스 밖 드래그를 확인한다.
3. Tab·N·방향키·P, 정지·재개·초기화를 확인한다.
4. 탭 숨김·복귀, 실험 반복 전환, hash 직접 진입·새로고침·뒤로/앞으로를 확인한다.
5. 1440/1024/390/320 화면과 모바일 회전에서 격자 가독성·배치를 승인 이미지와 비교하고 프레임 시간·메모리를 측정한다.

위 브라우저·실기기 검증은 실행하지 못했다. 60fps나 메모리 안정성을 보장하지 않는다. 08 이후는 구현하지 않았다.
