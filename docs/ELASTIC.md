# 04 Elastic — 구현 기록

## 범위와 변경 파일

04_ELASTIC만 구현했다. Gravity를 유지하고 Elastic을 추가했으며, 05 이후 장면은 기존 빈 캔버스다. 기존 화면·스타일·입력 관리자·단일 스케줄러·고정 1/60 업데이트를 재사용했다. SCSS 변경이 없으므로 CSS 컴파일은 실행하지 않았다.

- `js/scenes/elastic.js` 추가: Matter.js 0.20.0 스프링 제약, 원 세 개, 고정점과 네 방향 경계, 지그재그 Canvas2D 렌더링, 다중 포인터 잡기·놓기, 키보드 힘 입력, 강성·감쇠 제어, 생명주기 정리.
- `js/core/scene-manager.js` 수정: Elastic 모듈 지연 로딩 연결. 독립 RAF나 Matter.Runner는 사용하지 않는다.
- `js/app.js` 수정: Elastic 안내·슬라이더·로딩·정지·초기화 연결, 홈·목록·About의 제공 실험 안내 갱신. 초기화 시 두 물리 장면의 슬라이더 기본값을 복원한다.
- `index.html` 수정: 현재 단계 ELASTIC / 04 표기.
- `tests/elastic.mjs` 추가: 실제 Matter.js를 사용한 수치 안정성·입력·정리 검사.
- `docs/ELASTIC.md` 추가: 이 기록.

## 동작

`#elastic`에 접속한다. 고정점에 스프링으로 연결된 노랑·파랑·빨강 원을 잡아 늘린 뒤 놓으면 실제 제약 해석 결과에 따라 움직인다. 캔버스의 + 버튼을 누르면 원과 연결 스프링이 추가되며, 최대 9개까지 만들 수 있다. 새 원은 기존 스프링 체인의 끝에 연결된다. 스프링은 원의 가장자리 사이에 얇은 지그재그로 그린다. 첫 화면의 작은 물리적 변위가 초기 진동을 만든다. CSS/GSAP로 움직임을 대신하지 않는다.

중력은 0으로 두어 탄성에 집중한다. 강성은 0.005–0.2, 감쇠는 0–0.3 범위이며 기본값은 각각 0.04와 0.06이다. 감쇠 0에서도 작은 공기 저항은 유지하며 화면에 안내한다. 정밀 SI 단위 스프링 상수가 아닌 Matter.js의 모델 매개변수다.

과도한 힘을 방지하도록 포인터 목표 이동과 물체 속도를 스텝당 최대 12로 제한한다. 화면 밖 포인터도 내부 목표점으로 제한한다. 취소·캡처 해제·포커스 이탈·정지 시 잡기 제약을 해제한다. 초기화는 모든 매개변수를 기본값으로 복원하고 물체를 재생성한다. 크기 변경 시 매개변수를 유지하며 원과 경계를 재배치한다.

캔버스 포커스에서 N으로 원을 선택하고 방향키로 힘을 가한다. 슬라이더·정지·초기화는 기본 키보드 조작이 가능하다. 모바일에서는 기존 공통 레이아웃에 따라 설정이 캔버스 아래로 배치된다.

## 실제 검증

Node v22.23.4와 임시 폴더의 공식 Matter.js 0.20.0 빌드로 실행했다. npm·라이브러리 설치는 추가하지 않았다.

```sh
node tests/elastic.mjs /private/tmp/motio-matter-0.20.0.cjs
node tests/foundation.mjs
node tests/gravity.mjs /private/tmp/motio-matter-0.20.0.cjs
```

- 캔버스 폭 280/720, 강성·감쇠 양 끝값의 8가지 조합에서 19,200스텝 검사 통과. 유한 좌표·경계 유지·속도 안정성을 확인했다. 각 조합에서 추가로 120스텝 동안 원을 잡아 늘렸다.
- 기본 매개변수로 1,200스텝 후 마지막 60스텝의 속도 제곱 합이 처음 60스텝의 1% 미만으로 감소했다.
- 스프링 제어값 전달, 잡기 제약 생성/해제, 던지기 속도 상한, 포인터 취소, 키보드 힘 입력 검사 통과.
- 지그재그 선분 출력, pause/resume, resize 후 매개변수 유지, body/constraint 제거 및 동일 캔버스에서 100회 생성/종료 검사 통과.
- 기존 Foundation의 100회 전환·단일 RAF·비동기 경합 검사와 Gravity 회귀 검사 통과.
- 수정 JavaScript 구문 검사 통과.

검사는 브라우저 DOM과 포인터 이벤트 일부를 대역으로 사용한다. 실제 브라우저 렌더링·터치 캡처·성능·메모리 프로파일링을 대신하지 않는다.

## 수동 확인 절차와 남은 사항

1. 로컬 HTTP 서버로 `index.html#elastic`을 열고 원을 드래그해 늘렸다 놓는다. 네트워크의 Matter.js CDN 접근이 필요하다.
2. 강성·감쇠 최솟값/최댓값, 두 원 동시 터치, 빠른 드래그, 캔버스 밖 이동·취소를 확인한다.
3. Tab으로 캔버스·슬라이더·버튼에 접근하고 N·방향키를 확인한다.
4. 정지·재개·초기화, 탭 숨김·복귀, Gravity↔Elastic↔빈 장면, 뒤로/앞으로·직접 새로고침을 확인한다.
5. 1440/1024/390/320 화면에서 레퍼런스 대비 레이아웃·스프링 가독성과 실기기 회전·터치를 확인한다.

위 브라우저·실기기 확인은 이번 환경에서 실행하지 못했다. 60fps 및 메모리 안정성은 실측하지 않았으며 보장하지 않는다. 05 이후 구현은 진행하지 않았다.
