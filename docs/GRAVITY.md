# 03 Gravity — 구현 기록

03만 구현했다. 나머지 여섯 장면은 기존 empty scene을 유지하며 04 이후 기능이나 전환 효과는 추가하지 않았다. 승인된 색상·3열/모바일 레이아웃을 유지하고 기존 스타일을 재사용했다. SCSS/CSS 변경이 없어 이번에는 컴파일하지 않았다. 향후 컴파일은 사용자 지정 Live Sass Compiler를 사용한다.

## 변경 파일

- `js/scenes/gravity.js` 추가: Matter.js 0.20.0 엔진, 원 3개·사각형 1개, 삼각 경사면·바닥·좌우/천장 경계·세로 장애물, Canvas2D 플랫 렌더링. 중앙 관리자의 고정 업데이트에서만 엔진을 한 번 진행한다. 독립 RAF나 Matter.Runner는 없다.
- `js/core/tilt-input.js` 추가: 사용자 버튼 기반 권한 요청, HTTPS·지원 여부 확인, 중립 보정, 저역 통과 필터, 화면 방향 좌표 변환, 회전 시 재보정, 미지원/권한 거부/값 없음 안내, 종료 정리.
- `js/core/scene-manager.js` 수정: Gravity만 지연 로딩하고 초기화 성공 결과를 반환한다. 기존 단일 스케줄러와 오래된 로딩 취소 계약 유지.
- `js/core/libraries.js` 수정: 실제 사용에 맞춰 주석 갱신. 고정된 Matter.js CDN 지연 로더 재사용.
- `js/app.js` 수정: Gravity 설명·슬라이더·기울이기·보정 버튼, 로딩·오류 안내, 초기화 시 기본 매개변수와 센서 상태 복원. 홈·About·Settings의 구현 상태 갱신.
- `index.html` 수정: 현재 단계 표기 갱신.
- `tests/gravity.mjs` 추가: 실제 Matter.js를 사용한 물리 및 센서 계약 검사.
- `docs/GRAVITY.md` 추가: 이 기록.

## 동작

`#gravity`에서 원/사각형을 마우스·터치·펜으로 잡고 놓아 던진다. 각 포인터에 별도의 제약을 연결하며 이동 속도를 초당 좌표에서 물리 스텝 단위로 변환하고 최대 12px/스텝으로 제한한다. 실제 물체 이동과 충돌은 Matter.js가 처리한다.

중력은 0–19.6의 상대 세기이며 9.8이 기본값이다. 화면의 픽셀 단위 모델이므로 SI 길이·시간을 재현한 정밀 실험으로 간주하지 않는다. 반발과 마찰은 0–1 범위. 초기화하면 물체와 매개변수·기울이기를 기본 상태로 되돌린다. 화면 크기 변경 시 경계와 물체를 재배치하되 매개변수는 유지한다. 일시 정지·탭 숨김·포커스 이탈 시 드래그 제약을 해제한다.

캔버스에 키보드 포커스를 두고 N으로 물체를 선택하고 방향키로 힘을 가할 수 있다. 슬라이더는 기본 키보드 조작을 제공한다. 기울이기를 사용하지 않아도 드래그와 터치로 사용할 수 있다. 센서가 응답하지 않으면 대기 안내를 유지하며 끄기 버튼으로 해제할 수 있다. 센서 접근은 Gravity의 기울이기 버튼에서만 시작한다.

## 실제 검증

Node v22.23.4, Matter.js 0.20.0 공식 CDN 빌드를 임시 폴더에 받아 검사했다. 프로젝트에 npm이나 패키지 의존성은 추가하지 않았다.

```sh
node tests/foundation.mjs
node tests/gravity.mjs /private/tmp/motio-matter-0.20.0.cjs
```

- 기존 100회 장면 교체·단일 RAF·고정 스텝·비동기 로딩 경합 검사 통과.
- 실제 엔진에서 2,400 스텝 실행, 유한 좌표·좌우와 바닥 경계 이탈 여부 확인 통과.
- 리사이즈 후 물체 4개 재생성, 포인터 제약 생성/해제, 던지기 속도 상한 확인 통과.
- 정지 시 엔진 시간 불변, 재개 시 진행, destroy 후 body/constraint 제거 확인 통과.
- 센서 권한 거부/허용, 중립 보정, 필터, 90도 좌표 변환, 종료 후 센서 이벤트 해제 및 늦게 끝난 권한 응답 무시 확인 통과.
- 수정 JavaScript 구문 검사 통과.

자동 검사는 브라우저 DOM과 센서 일부를 대역으로 사용한다. 실제 포인터 캡처, 터치감, 화면 배치, 시각적 충돌 자연스러움, 장시간 메모리 사용을 검증한 것은 아니다.

## 수동 확인 절차와 남은 사항

로컬 HTTP 서버로 `index.html#gravity`를 연다. CDN 연결이 필요하다.

1. 1440/1024/390/320px에서 실험·컨트롤 배치, 원과 경사면 비율, 키보드 포커스를 확인한다.
2. 드래그·던지기·동시 터치, 반발/마찰/중력 슬라이더의 양 끝, 물체 쌓기와 장애물 충돌을 확인한다.
3. 정지·재개·초기화, 탭 전환, Gravity와 다른 장면 반복 이동, 뒤로/앞으로 및 직접 새로고침을 확인한다.
4. 모바일 HTTPS에서 기울이기 권한 허용/거부, 기준점 보정, 세로/가로 회전과 터치 대체 입력을 확인한다.
5. 브라우저 메모리와 프레임 시간을 측정한다.

위 브라우저·실기기 확인은 이번 환경에서 실행하지 못했다. 60fps나 완전한 터널링 방지를 보장하지 않는다. 특히 센서 좌표 방향과 권한 UX는 iOS/Android 실기기 확인이 남아 있다.
