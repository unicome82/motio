# 메인 썸네일 탭 UI

- 헤더의 Experiments·About·Settings 메뉴와 각 독립 화면을 제거했다. 각 실험의 조작 패널은 유지한다.
- 홈은 비주얼과 일곱 썸네일 탭을 보여준다. 썸네일 선택 시 비주얼을 숨기고 탭 아래의 공통 패널에 실험을 표시한다.
- 실험 상태에서는 탭을 작게 정리하고 캔버스 높이를 화면에 맞춘다. 별도 목록·이전/다음 탐색은 썸네일 탭으로 통합했다. 로고는 홈으로 돌아간다.
- 태블릿·모바일은 탭을 가로로 스크롤한다. 설정은 기존 반응형 흐름에 따라 캔버스 아래로 배치하며 페이지 스크롤은 유지한다.
- tablist/tab/tabpanel, aria-selected, aria-controls, 활성 탭에 연결된 패널 이름을 제공한다. 방향키/Home/End는 탭 포커스 이동, Enter/Space는 선택이다. 현재 선택된 탭을 다시 눌러도 실험을 초기화하지 않는다.
- hash 직접 진입·새로고침·뒤로/앞으로 탐색은 유지한다. 삭제한 화면의 예전 hash는 홈으로 연결한다.
- 탭 이동 전에 이전 물리 장면과 UI 이벤트를 정리한다. 숨긴 홈 Canvas를 실험 Canvas로 선택하지 않도록 패널 범위에서 조회한다. 홈 비주얼도 실험 중에는 업데이트하지 않는다.

변경 파일: index.html, js/app.js, js/core/router.js, js/core/experiment-tabs.js, scss/style.scss, scss/style.css, README.md, tests/tabs.mjs, tests/tab-view.mjs.

설치된 Live Sass Compiler의 내장 Sass 엔진으로 CSS를 생성했다. 기존 물리·수명주기 검증과 새 탭·화면 전환 검증을 실행했다. 탭 UI 검사는 DOM 대역을 사용한다. 실제 브라우저의 1440/1024/390/320 배치·터치·스크롤 화면 검증은 아직 수행하지 않았다.

## 클릭 전환 보완

- GSAP를 async 로딩해 외부 CDN 대기가 로컬 앱 부팅을 막지 않도록 변경했다.
- 썸네일 클릭은 Router.navigate로 기록을 추가하고 즉시 화면을 갱신한다. 해시 이벤트에만 의존하지 않으며, 같은 탭을 다시 클릭하면 실험을 재생성하지 않는다. Ctrl/Command 클릭은 기본 링크 동작을 유지한다.
- 화면 전환 검증은 해시를 직접 바꾸는 방식에서 실제 탭 click 이벤트를 발생시키는 방식으로 보강했다. 브라우저 기본 이벤트/렌더링은 대역이므로 실기기 확인은 별도다.
