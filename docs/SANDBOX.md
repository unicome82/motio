## 사용과 한계

`#sandbox`에서 버튼으로 물체를 추가한다. 실제 겹침 검사로 빈 위치를 찾으며 공간이 없으면 추가하지 않고 안내한다. 편집 물체는 최대 24개이며 경계 네 개는 별도다. 원과 상자는 동적, 경사면과 발판은 고정 물체다. 기본 구성은 경사면·상자·원이다.

물체를 누르면 선택 윤곽선과 현재 속성이 표시된다. 질량은 동적 물체에만 적용하고 고정 물체에서는 비활성화한다. 마찰·반발은 선택 물체, 중력은 전체 엔진에 적용한다. 물체 삭제 버튼과 Delete/Backspace, N 선택 순환과 방향키 위치 이동을 지원한다.

동적 물체는 실행 중 제약으로 잡아 움직인다. 고정 물체와 정지 중 물체는 위치를 직접 편집한다. 정지 중에도 추가·이동·삭제 결과를 즉시 다시 그린다. 한 번에 한 물체를 드래그하며 작은 물체에는 가까운 중심점 선택 범위를 제공한다. 손을 놓으면 드래그 제약을 제거하고 물리 계산을 이어간다.

물체 이동 속도와 드래그 목표 이동량을 제한한다. 빽빽한 편집 배치에서 충돌 해석만으로 경계를 넘는 경우에 대비해 업데이트 후 경계 안으로 보정하고 해당 축 속도에 반발을 반영한다. 일반 충돌은 Matter.js가 계산한다.

초기화·장면 이탈·화면 크기 변경 시 편집 내용은 초기화한다. 크기 변경 시 전체 중력은 유지한다. DPR만 변경되면 편집 상태를 유지한다. 초기화는 중력과 기본 물체 구성을 복원한다. 저장/불러오기는 프롬프트의 선택 사항이며 이번에는 구현하지 않았다. 저장되지 않는다는 점을 화면에 표시한다.

## 실제 검증

Node v22.23.4와 기존 임시 파일 Matter.js 0.20.0으로 실행했다. npm 설치는 추가하지 않았다.

```sh
node tests/sandbox.mjs /private/tmp/motio-matter-0.20.0.cjs
```

- 폭 280/720 × 중력 0/19.6에서 총 4,800스텝: 유한 좌표·경계 확인.
- 네 종류 물체 추가, 빈 위치 탐색, 24개 상한, 물체 이동·삭제와 엔진 정리 확인.
- 선택에 따른 질량 활성/비활성, 질량·마찰 적용, 정지 중 이동과 즉시 렌더링 확인.
- 동적 드래그 제약 생성, 선택 물체 삭제 시 제약 제거, resize 후 기본 구성 확인.
- 100회 생성/종료 및 종료 후 버튼 이벤트 해제 확인.
- 기존 Foundation·Gravity·Elastic·Magnetism·Wave·Cloth 회귀 검증과 수정 JavaScript 구문 검사 통과.

숫자 계산은 실제 엔진을 사용하지만 Canvas·DOM·포인터 일부는 대역이다. 브라우저 화면·실기기 입력·프레임 시간·메모리 검증을 대신하지 않는다.

## 남은 수동 확인

로컬 HTTP 서버의 `index.html#sandbox`에서 네 종류 추가 → 선택 → 속성 조절 → 드래그 → 정지 중 편집 → 삭제 → 초기화를 확인한다. 키보드 N/방향키/Delete와 슬라이더, 물체 수 상한·공간 부족 안내, 탭 숨김·복귀와 hash 탐색도 확인한다.

1440/1024/390/320 화면과 실제 모바일 회전·터치에서 설정 배치와 물체 선택감을 비교하고 성능을 측정해야 한다. 이 브라우저·실기기 검증은 실행하지 못했다. 08 및 10 이후 구현은 진행하지 않았다.
