## 동작과 수치 모델

`#wave`에서 누른 위치에 충격을 가한다. 누른 채 유지하는 것만으로 충격을 반복하지 않는다. 다음 고정 업데이트 전에 손을 떼는 짧은 입력도 대기열에 남겨 처리한다. 동시 터치는 최대 4개, 대기 충격은 최대 16개로 제한한다. 캔버스에 키보드 포커스를 두고 방향키로 위치 선택, Enter/Space로 파동을 만든다. 반복 키 입력은 충격을 재생성하지 않는다.

실제 2차원 높이 격자의 유한 차분을 계산한다. 캔버스 상단 약 40%는 비워 두고, 가로 격자선을 아래쪽 약 60% 높이 안에서 변위시켜 얇은 선으로 그린다. 렌더링 변위만 ±20으로 제한하며 수치 검증을 숨기는 높이 클램프는 하지 않는다. 완전한 유체 시뮬레이션, 유체 이송·난류 계산 또는 정확한 물의 물성 재현으로 표시하지 않는다.

속도 100–300, 감쇠 0.4–4, 기본값은 180/1.8이다. 이는 화면 단위 모델의 제어값이다. 고정 경계에서 반사하고 시간이 지나며 감쇠한다. RK4와 CFL 한계에 맞춘 내부 세분화를 사용한다. 속도로 정규화한 상태를 적분해 속도 변경 시 불필요한 에너지 주입을 줄인다. 모든 내부 스텝은 중앙 update 호출 안에서 수행한다.

캔버스 폭 480 미만은 셀 간격 약 12, 그 외 약 8을 사용한다. 격자는 각각 최대 80×72 / 128×96으로 제한한다. 배열 8개를 재사용하고 프레임마다 배열을 생성하지 않는다. 화면 크기 변경은 파동을 비우고 새 격자를 구성하며 설정값을 유지한다. DPR만 변경되면 기존 격자를 유지한다.

정지 시 대기 입력을 비우고 새 충격을 받지 않는다. 초기화는 평평한 격자와 기본 제어값으로 복원한다. 종료 시 이벤트·대기열·수치 배열·캔버스 참조를 해제한다. 독립 RAF·타이머·Matter 엔진·추가 의존성은 없다.

## 실제 검증

Node v22.23.4에서 다음 검사 통과:

```sh
node tests/wave.mjs
node tests/foundation.mjs
node tests/gravity.mjs /private/tmp/motio-matter-0.20.0.cjs
node tests/elastic.mjs /private/tmp/motio-matter-0.20.0.cjs
node tests/magnetism.mjs
```

- 280×300 / 720×500 / 2×2 크기, 속도·감쇠 양 끝 12개 조합에서 총 21,600스텝: 유한 상태와 높이 범위 확인, 초기 대비 1% 미만 감쇠 확인.
- 1,200회 강한 반복 충격과 매 스텝 속도·감쇠 양 끝 전환에서도 발산 없이 유한 상태 유지.
- 고정 상하 경계, 모바일 격자 축소, 배열 해제 확인.
- 두 위치의 짧은 입력, 일시 정지, 슬라이더 전달, 키보드 충격, 크기 변경, 100회 생성·종료 확인.
- Foundation·Gravity·Elastic·Magnetism 회귀 검증 및 수정 JavaScript 구문 검사 통과.

자동 검사는 실제 수치 배열을 사용하지만 브라우저 DOM과 Canvas 호출은 대역을 사용한다. 브라우저 프레임 시간·터치 이벤트 순서·시각적 품질·장시간 메모리 사용의 검증을 대신하지 않는다.

## 수동 확인과 남은 사항

로컬 HTTP 서버에서 `index.html#wave`로 접속한다.

1. 여러 위치를 탭해 파동의 전파·간섭·감쇠를 확인한다.
2. 다중 터치와 빠른 탭, 속도·감쇠 양 끝, 정지·재개·초기화를 확인한다.
3. Tab으로 캔버스와 컨트롤에 접근하고 방향키·Enter·Space를 확인한다.
4. 탭 숨김·복귀, 직접 새로고침, 뒤로/앞으로, 기존 실험과 반복 전환을 확인한다.
5. 1440/1024/390/320 화면과 모바일 회전에서 선의 가독성·비율을 레퍼런스와 비교하고 프레임 시간·메모리를 측정한다.

브라우저 화면 비교와 실기기 터치·회전 검증은 실행하지 못했다. 성능 목표는 실제 브라우저 측정이 남아 있으며 60fps를 보장하지 않는다. 07 이후 기능은 구현하지 않았다.
